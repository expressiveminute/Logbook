# Overview
This is a private project and should be treated as such.

The app is in a very early state. Bugs may occur. 

# ✨ Features

It is a comprehensive flight tracking and analysis application built entirely with AI assistance.

- Flight Tracking: Record and monitor your flights with detailed metadata
- Analytics & Insights: Analyze flight patterns, performance metrics, and trends
- Data Visualization: Comprehensive dashboards for your aviation data

# 🛡️ Privacy First

- Designed as a private solution
- No internet access needed; every data remains on the device
- Backups saved locally as CVS

As stated at the beginning: This is a private project and should be treated as such.

Please respect the privacy intentions of this repository. While it is open source under GPL-3.0, certain aspects may remain intentionally private or configurable for self-hosting purposes.

BUT: Feel free to contact me and ask we for any new features.
